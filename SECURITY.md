# Security policy

## Reporting a vulnerability

Report vulnerabilities through GitHub's private vulnerability reporting by
opening a [draft advisory](https://github.com/hoferan/huemi/security/advisories/new).
That keeps the report private until a fix is available.

Please do not open a public issue for a security problem.

Expect a first reply within a week. This is a personal project, so response
times depend on availability.

## Supported versions

There are no releases yet. Only the current `main` branch is supported.
